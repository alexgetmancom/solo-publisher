# Phases 4–7 — work split

Remaining TypeScript (bot and domain core are ported): runtime foundation, delivery + social adapters, channels,
observability probes, Telegram worker loops, Story-card renderer, site jobs + public read model, HTTP edge,
operations registry/CLI/MCP, runtime wiring, packaging.

|---|---|---|
| `runtime` | `foundation/http.ts`, `foundation/runtime/*`, `foundation/scheduler.ts`, `foundation/worker-signal.ts`, `foundation/external/*`, `foundation/deployment.ts` (if not already in `bot`) | foundation, db, domain |

`app` wires everything (`runtime/workers.ts`, `server.ts`, `docker-entrypoint.ts`); `unported.rs` shrinks to nothing (now `app/src/host.rs`, the host and nothing else).

## Waves

1. `runtime`, `story_render`, `public_site` (independent).
2. `adapters` (by platform family), `delivery` publish workflow + reconciliation + media, video worker + YouTube,
   channels + OAuth + tokens, observability probes + Telegram loops.
3. Site jobs, workers wiring in `app`, `http`.
4. `ops` (registry → CLI + MCP).
5. Stories sidecar, Dockerfile, compose, CI job for Rust, canary on Maru, cutover.

## Parity per slice

- Pure logic: fixtures generated by `scripts/rust/<slice>-fixtures.ts`, replayed in Rust.
- DB effects: TS-vs-Rust scenario harness (same steps, fixed clock, compare result + tables).
- HTTP to platforms: request goldens — the TS adapter runs against a recording `fetchImpl` with canned responses;
  the Rust adapter runs against a recording transport; method, URL, headers (minus secrets), body compared.
- Public site: `/api/public/site` body and ETag byte-identical on the fixture DB and on a copy of the prod DB.

## Shared rules for every slice

- Worktree per slice under `_trash-rust/wt/<slice>`, branch `rust-<slice>`; `CARGO_TARGET_DIR=_trash-rust/target-<slice>`.
- No network to real platforms, no secrets in files, the prod DB copy only as a copy in `_trash-rust/`.
- English code, comments, logs; Russian only in product strings (`ru.json`).
- `cargo test --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo fmt --check` green.
